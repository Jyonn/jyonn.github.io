推荐项目

Legommenders

面向内容推荐研究的模块化 PyTorch 库，支持用语言模型构建和评测推荐系统。

在同一套训练流程中替换物品编码器、用户行为建模模块和打分模块，并可通过 xMIND 教程跑通多语言新闻推荐实验。

  • 推荐系统
  • 框架
  • PyTorch
  • 大语言模型
项目详情 ↗ GitHub ↗ 文档 ↗ 论文 ↗

RecBench

面向点击率预测和序列推荐的评测基准，用于比较大语言模型与传统推荐系统。

可在 RecBench 中比较不同的物品表示方式，再用扩展项目 RecBench-MD 评估模型在不同数据集与领域之间的迁移能力。

  • 推荐系统
  • 评测基准
  • 数据集
  • 大语言模型
GitHub ↗ 数据集 ↗ RecBench-MD ↗ 论文 ↗

RecBase

合作研发的生成式推荐基础模型，通过预训练支持跨领域零样本推荐。

RecBase 把物品编码为分层概念标识符，并从多个领域的用户交互序列中学习预测下一项物品。

  • 推荐系统
  • 生成式推荐
  • 零样本
  • 大语言模型

开源工具

UniTok

面向机器学习数据集的预处理库，统一处理文本、类别和数值特征。

可为每一列指定分词或编码方式，并让使用相同特征的数据集共享词表。

  • Python
  • 机器学习
  • 数据处理
文档 ↗ PyPI ↗

autoencoders

面向表征学习研究的 PyTorch 工具库，涵盖确定性、变分和量化自编码器。

可通过统一接口训练不同类型的模型，保存检查点并在后续实验中复用。

  • 机器学习
  • PyTorch
  • Python
PyPI ↗ GitHub ↗

GPUOps

面向科研团队的共享 GPU 运维命令行工具。

可查看每张显卡的占用用户、进程、显存和利用率，并记录和汇总 GPU 使用时长。

  • 命令行
  • 实验室工具
  • 运维
PyPI ↗ GitHub ↗

SmartDict

解析嵌套数据结构中字段引用的 Python 库。

可让多个派生字段引用同一个值，为缺失值提供默认值，并检测循环引用。

  • Python
  • 配置
  • 数据处理
PyPI ↗ GitHub ↗

RefConfig

基于 SmartDict 的配置加载工具，支持用可复用的配置文件组装实验。

可将数据集和训练参数分别写入不同文件，再引用两者的字段生成检查点路径。

  • Python
  • 配置
PyPI ↗ GitHub ↗

Nestify

将带路径式键名的扁平字典转换为嵌套结构的 Python 工具。

可展开 user.profile.name 这类路径式键名，并指定路径与已有值冲突时的处理方式。

  • Python
  • 数据处理
  • 配置
PyPI ↗ GitHub ↗

Oba

为字典等容器提供属性式访问的 Python 工具。

可用点号读取和修改嵌套字段，再取出普通的 Python 容器。

  • Python
  • 数据处理
PyPI ↗ GitHub ↗

Diq

将类实例转换为字典的 Python 序列化工具，适用于 API 响应和数据导出。

可选取和重命名导出字段，也可为单个属性自定义序列化结果。

  • Python
  • 序列化
  • 后端开发
PyPI ↗ GitHub ↗

SmartDjango

面向 Django API 开发者的工具集。

可校验请求参数、统一错误响应格式，并用 ORM 辅助函数编写常见查询。

  • Python
  • 后端开发
PyPI ↗ GitHub ↗

Notificator

帮助应用接入多渠道通知的 Python SDK。

可分别准备邮件、短信和 Webhook 通知，再用一次 API 请求统一提交。

  • Python
  • 后端开发
  • 运维
PyPI ↗ GitHub ↗

CertBuddy

面向腾讯云与七牛云运维人员的 HTTPS 证书管理工具。

可通过腾讯云 DNS 验证申请证书，将证书部署到七牛云，并续期即将到期的证书。

  • Python
  • 命令行
  • 运维

Pigmento

为终端输出着色并标明消息来源的 Python 工具。

可把调用函数或方法显示为带样式的前缀，便于区分程序各处的输出。

  • Python
  • 命令行
PyPI ↗ GitHub ↗

ImageGrid

面向相册与拼图场景的浏览器图片排版库。

可将宽高比不同的图片排成自适应网格，在线预览布局并导出 PNG。

独立应用

Chronelle · 时序

用来安排一周日程、与他人协调时间的日历。

可以邀请他人参加日程，也可以共享访客视图，本站的只读周历就是一例。

  • 日历
  • 协作
  • iOS
网站 ↗ 演示 ↗

Frienden · 友间

以朋友和共享空间组织会话的即时通信应用。

可以在空间里私聊或群聊，也能用同一账号登录小兜和留幅。

  • 社交
  • 协作
  • 网页应用
网站 ↗

StillFolio · 留幅

面向摄影创作者的相册整理和作品集发布工作台。

可以离线编辑相册，联网后发布可分享的副本，也可以随时撤销链接。

  • 摄影
  • 创作工具
  • 离线使用

Pocklo · 小兜

可以在浏览器和命令行里使用的文件工作区。

在终端里上传本地文件夹，网页端会保留原有的目录结构。

  • 文件管理
  • 网页应用
  • 命令行

Monifa · 时符

可以在网页和终端管理动态验证码的身份验证器。

离线时，命令行仍能为此前同步过的账户生成验证码。
