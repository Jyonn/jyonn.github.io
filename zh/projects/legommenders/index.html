Legommenders

一个面向大模型时代的内容推荐研究库，强调模块化、可复用与实验表达力。

GitHub 论文

Legommenders 不是单纯的代码整理，更像是一个研究表达工具箱。它试图把内容推荐、特征建模和大模型接口组织成一套能快速试验、也能更容易复现的系统结构。

我希望一个研究项目不仅服务于一篇论文，还能积累为后续问题提供更好的起点。
